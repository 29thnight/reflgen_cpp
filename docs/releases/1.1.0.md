# reflgen 1.1.0

1.0.1 이후의 기능 추가 릴리스다. 기존 C++20 런타임 API와 헤더 생성 경로를 유지한다.

- `import reflgen.json` 등 named library module 제공.
- MSVC IFC 기반 exported public 타입의 스키마·런타임 등록·직렬화 생성.
  같은 설정으로 전처리한 sidecar를 통해 reflgen 및 모듈에서 export한 사용자 어트리뷰트 처리.
- 헤더/모듈 혼합 MSBuild 프로젝트의 자동 경로 분리와 VS 저장 시 재생성.
- 표준 어트리뷰트와 reflgen 자동완성 공존, C++ 버전별 목록 및 C++26 typed annotation 입력 지원.
- C++26 표준 리플렉션/annotation 백엔드의 기능 검사와 AUTO/STD/LEGACY 선택.
  내부 언어/기능 매크로를 통합하고 C++23 binary 실수 I/O 경로를 추가했다. wire 형식은 유지한다.
- 선언 메타데이터 JSON, 명시한 메서드의 C ABI/C# interop 생성 및 소비 검사 포함.
- Windows zip/NuGet/vcpkg 배포 배선에 IFC 생성기, 모듈 소스, 표준/혼합 targets와 의존성 라이선스 포함.

현재 MSVC 19.51의 AUTO는 기존 헤더/IFC 경로를 사용한다. 표준 백엔드의 실행은 GCC 16.2에서
검증했다. 자동 표준 스키마는 public 멤버에 한정되며 등록할 클래스 목록을 명시해야 한다.
`[[reflgen::...]]`와 `[[=reflgen::...]]` 소스 표기는 자동 변환하지 않는다.

VS 2026 실제 재설치, 자동완성 입력·확정, 저장 경로 분리, ignore 제외, 오류 이동·복구,
IntelliSense 새 모듈 필드 인식, Release F5 종료 0을 확인했다.
[검증 기록](../verification-2026-10-17.md#final-live-vs-verification)과
[백엔드 가이드](../reflection-backends.md)에 환경·제약·재현 경로를 정리했다.

업데이트 시 생성기·헤더·VSIX를 같은 버전으로 맞추고 생성 파일과 IFC를 재생성한다.
IFC 호환성은 해당 MSVC/IFC SDK 조합에 의존한다. 소스 빌드에서 IFC 생성기를 켜면 고정한
Microsoft IFC SDK/GSL 소스를 최초 구성 시 가져온다.

게시 후에는 nuget.org에서 1.1.0을 격리 복원하고 GitHub 릴리스 VSIX 1.1.0을 설치해
VS Community 2026 18.11.0에서 추가 검증했다. 헤더·모듈 혼합 프로젝트의 C++20 Debug /
C++latest Release F5 실행이 종료 코드 0으로 끝났고, 저장 경로 분리·ignore 제외·표준/reflgen
자동완성 입력·확정·Error List 이동/복구·새 모듈 필드 IntelliSense 표시를 확인했다.
[게시된 패키지 실검증](../verification-2026-10-17.md#nuget-110-and-released-vsix-verification)에
릴리스 파일 식별과 이번 검증의 범위를 별도로 기록했다.
